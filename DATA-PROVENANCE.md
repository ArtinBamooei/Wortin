# Data provenance and attribution

Wortin's vocabulary records were imported from a Goethe-Zertifikat B1 vocabulary-list source and enriched with Persian meanings, examples, and grammar notes.

The source list is not represented as an official Goethe product, and Goethe does not endorse Wortin. Persian meanings and grammar annotations are project additions and are not independently certified by Goethe.

The repository does not currently contain a verified redistribution license for the source vocabulary dataset. The MIT license in LICENSE applies only to original application source code; it does not license the dataset or third-party assets. Confirm the source document's current terms and obtain any required permission before redistributing the underlying dataset or a derivative export.
